# SAD_musicplayer

Music Playlist Manager e un'applicazione desktop pensata per creare e gestire playlist musicali. Il progetto include la gestione del catalogo dei brani, l'organizzazione in playlist, una riproduzione simulata con modalita sequenziale, shuffle e loop, funzioni di undo per le operazioni principali e strumenti per statistiche e playlist automatiche.
